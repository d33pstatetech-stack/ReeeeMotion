User Guide · v1.0

Remotion Video Editor

A fully local, free, open-source web-based video editor. Drag clips and images onto a timeline, tweak Remotion variables (scale, opacity, rotation, transitions, spring entrances), and export the final video as MP4 — all from a React + Vite frontend that talks to a Node + Express backend that uses Remotion's bundler and renderer to produce the final video headlessly.

Section 1 Quickstart — your first 90 seconds #

The whole app is built around one loop: upload → arrange → tweak → export. Walk through it once, then you can ignore this guide for everything except the harder knobs.

  1. Upload some media
    Click Upload in the top-left Media Bin — or just drag files in. Video, image, and audio are all accepted (max 500 MB each). Each upload shows up as a tile in the bin.
  2. Drag a clip onto a timeline lane
    Drag a video/image to the top lane, or an audio file to the middle lane, or click + Text for an instant text overlay. Drop it where the green guide line shows the timestamp you want.
  3. Tweak it in the Property Inspector
    Click the clip to select it. The right-side panel shows everything you can change: timing (start, in, out), transform (scale, opacity, rotation), transitions, and for video & image — entrance physics with a real spring.
  4. Watch, then export to MP4
    The top-center panel is a frame-perfect Live Preview at your current canvas size (720p, 1080p, vertical 9:16, square 1:1). Press Space to play/pause. When you're happy, click Export MP4 in the top toolbar — the server renders the timeline and downloads the MP4 for you.
Tip Every change you make is shown in the preview instantly. You don't need to render to check your work — only to download the final video. Save render time by previewing first, exporting last.

Mental model in 30 seconds

 [Media Bin]  →  [Timeline]  →  [Preview]  →  [MP4]
  your raw clips      ordered on a 3-lane       live render         final file
                      horizontal track          of your timeline
Heads-up

You do not need to know code, React, or Remotion to use this app. Everything happens in the UI. If you ever see a "Remotion variable" mentioned in this guide, that's just the name of something the Property Inspector slider controls — it's not asking you to write any.

Section 3 Uploading media #

The Media Bin accepts three kinds of files, all under 500 MB each.

KindFormats acceptedWhat happens on drop
Video MP4, WebM, MOV Uploads → appears as tile → drag onto top lane → auto-trims to full source duration.
Image PNG, JPG, WebP, GIF Uploads → appears as tile → drag onto top lane → defaults to a 5 second still.
Audio MP3, WAV, M4A, OGG Uploads → appears as tile → drag onto middle lane (or click + Add).
Tip

The file picker uses MIME-type wildcards (video/*, image/*, audio/*) — so any format your browser recognises works, not just the list above. The list is what we test by default; less common formats (AV1-encoded WebM, HEIF images, OGG Vorbis, FLAC audio, M4A) usually work because the browser maps them to whatever <video> / <audio> tags know how to play.

Two ways to upload

  • Click the dashed drop zone (or the Upload button) and pick files.
  • Drag & drop any video, image, or audio file from your desktop onto the bin.
Heads-up

Files are uploaded to the local server (server/uploads/) and referenced by URL inside your project. If you share a timeline by URL, recipients need to have the same media files uploaded on their machine for the media to play — the timeline only stores media URLs, not the bytes. For a portable backup, use Save to download a .remotion.json alongside your media files.

From bin → timeline

  1. Click any tile's + Add button to drop the clip on the timeline at the playhead.
  2. Or drag the tile onto the lane you want — drop the mouse anywhere with a green guide line to land there.

Section 5 Editing video & image clips #

Click any video or image clip on the timeline and the Property Inspector on the right shows four sections of controls.

1. Timing — when & how long

FieldWhat it controls
StartWhere on the timeline the clip begins playing (seconds from 0).
In-pointWhere in the source media the clip begins (trim the start of the file).
Out-pointWhere in the source media the clip ends (trim the end of the file).

2. Transform — how it looks

FieldWhat it controls
ScaleResize. 1.00× = fits the canvas perfectly. Larger = zooms in, smaller = shrinks.
OpacityTransparent → opaque. 100% = fully visible. 50% = half-transparent and lets the clip below show through.
RotationRotate around the clip's center, from -180° to 180°.

3. Transitions — fade in & out

Each clip has an enter transition (the way it appears, blending into whatever was before it) and an exit transition (the way it disappears, blending into whatever comes after). Pick a style — None, Fade, Wipe, Slide ←, Slide →, Flip — and a duration.

Practical patterns

Cross-fade blend: Set the previous clip's exit to Fade with the same duration as the next clip's enter Fade. They cross-blend across the overlap.

Quick chat cut: Both clips use None for both transitions — hard cut.

4. Entrance Physics — the Remotion spring

The most distinctive feature of this editor. Toggle the eye icon on the right of the section header to turn it on, then tune four numbers:

KnobPlain English
MassHow heavy the moving object feels. Higher = slower fall, more inertia.
DampingHow quickly the bounce settles. Low = bouncy, high = no overshoot.
StiffnessHow snappy the spring is. Higher = snaps into place fast.
DurationMax time the entrance window can last (seconds). Acts as a safety cap.
From X / Y / Scale / OpacityWhere the clip starts from at frame 0 of its entrance. The final rest pose is the Transform values above.
Try this

Mass 1, Damping 10, Stiffness 100, From Scale 0.5, From Opacity 0 — that's the satisfying "pop-in" preset most editor UIs use by default.

Section 6 Editing audio clips #

Select any green card on the audio lane. The Property Inspector shows two sections.

Volume

Loudness. 100% is the source's natural level. 200% is a loud boost (may clip / distort — avoid it on already-loud sources).

Fade In / Fade Out

Smooth ramp from silence (fade in, at the start of the trim) or to silence (fade out, at the end). Use 0.2–0.5 seconds for natural transitions.

Timing & trimming

Identical to video clips — same Start, In-point, and Out-point sliders. The amber handles on the timeline work the same way. Audio clips never get cross-fades from the transition layer; fade yourself, or layer two audio clips overlapping.

Common audio recipes

Voice-over on a song: Drop the song at 0:00 with Volume at ~40% and a Fade Out of 2 seconds at the end. Drop the voice clip at 0:05 with Volume at 100% and a Fade In of 0.2 seconds.

Cut-down music for a slideshow: Set both Fade In and Fade Out to 1 second, trim the source to the exact length of your slideshow clips.

Section 7 Editing text clips #

Text clips are their own thing: a headline, a caption, a watermark. Click any cyan card on the text lane to edit it.

The four sections of the text inspector

SectionKnobs
Text (top) Multi-line content (\n for line breaks), font family (4 system-safe presets), font size (16–400 px), font weight (100–900), color (7 presets + freeform hex), background opacity (0–100% black pill), alignment (left/center/right).
Timing When the text becomes visible (Start) and how long it stays on screen (Duration, capped at 60 s).
Position X and Y offsets in pixels from canvas center. Positive X → right, positive Y → down.
Tip

Text clips always enter with a gentle spring by default — you don't need to toggle anything to get nice cursor-friendly motion on a headline. If you want no motion, set entrance.enabled = false via JSON in the saved project file, or just rely on the default tick.

Heads-up

The font picker offers system-safe stacks only — anything you type in the freeform font field must be installed on the machine that RENDERS the MP4. If you need a non-system font in your video, you'd need to install it on the server (Docker side) — see CONTRIBUTING.md.

Section 8 Transitions & entrance physics #

A quick reference to every transition plus a deeper primer on the spring physics — because once you've used it once, you can't go back.

Transition cheat sheet

TypeLookBest for
NoneInstant changePunchy edits, dialog, news-y feels.
FadeOpacity ramps 0→1Cross-blending between two clips (use the same duration on both ends).
WipeEdge sweepTravel / change-of-scene feels.
Slide ←New clip pushes the previous one leftContinuous scroll, like a phone swipe.
Slide →New clip pushes the previous one rightSame but reversed direction.
Flip3D rotation around the vertical axisCard-flipping reveal, "now we look at this".

Springs — the deeper primer

Each clip can have an entrance animation driven by a real spring (not a keyframe or an easing curve). A spring simulates how a physical object bounces when pushed. Two ingredients control it: how much force pulls it back and how much friction slows it down.

Stiffness ↑

Snappier. Reaches the rest pose faster. Best for short, punchy entrances.

Damping ↑

Less overshoot. At very high damping the motion becomes over-damped (no bounce). At low damping it oscillates.

Mass ↑

Slower and lazier. Higher mass means the same force produces less acceleration.

From X / Y / Scale / Opacity

Where the clip starts. The spring pulls from there toward the rest pose (Transform values). Negative Y = above center.

Recipes

Calm fade-up: Mass 0.5, Damping 14, Stiffness 140, From Opacity 0 (the text default). Soft, no bounce.

Bouncy pop: Mass 1, Damping 8, Stiffness 200, From Scale 0.3. Squashes in, bounces once.

Heavy thud: Mass 3, Damping 20, Stiffness 300, From Y -200. Falls in from above and stops dead.

Section 10 Save, share & load projects #

Three ways to persist work. They each capture exactly the same JSON shape: a .remotion.json file with one timeline inside.

💾 Save

Downloads a .remotion.json file (your project name + that extension). Save it anywhere: next to your media folder is best.

🔗 Share

Copies a URL that contains the timeline JSON to your clipboard. The URL is automatically loaded when someone opens it in the app.

↥ Load

Replaces the current timeline with a saved .remotion.json file from disk. Any unsaved edits are lost (Ctrl+Z only restores in-memory history).

What's actually in the JSON?

{
  "version": 1,
  "kind": "remotion-editor-project",
  "name": "my-video",
  "savedAt": "2025-07-10T12:34:56.000Z",
  "timeline": {
    "fps": 30,
    "width": 1920,
    "height": 1080,
    "backgroundColor": "#000000",
    "clips": [ ... ],          // video / image clips
    "audioClips": [ ... ],
    "textClips": [ ... ]
  }
}
Heads-up

Sharing by URL works for small projects. If your timeline approaches thousands of characters, the toast will say "Project too large for a URL. Use Save instead." For typical projects (a few minutes of video) the limit is comfortably generous.

The toolbar remembers the last 5 project names you used — the Recents dropdown lets you quickly rename-and-save without typing.

Section 11 Exporting to MP4 #

The final step. The server bundles the composition, renders it frame-by-frame with headless Chrome, and downloads the MP4.

  1. Click Export MP4 in the top toolbar.
  2. The progress bar appears and updates as the renderer works. Render time depends on timeline length and source media complexity; a 30-second 1080p clip typically takes 15 – 60 seconds.
  3. When done, the MP4 is automatically downloaded by your browser. You also get a Last render link next to the button — click it to open in a new tab.

What "Export" actually does

Behind the scenes the server:

  1. Uses @remotion/bundler to bundle compositions/ + your timeline JSON into a self-contained Webpack bundle.
  2. Uses @remotion/renderer to spin up headless Chrome, drive it frame-by-frame through the bundled composition, and capture each frame to an MP4.
  3. Streams the finished MP4 back to the browser, which triggers the file download.

If the export fails

The first thing to try is saving the project and looking at the toast for the error. Common causes:

  • A media URL in the timeline points to a file the server can't reach (deleted from the Media Bin, or you renamed the file between sessions).
  • The server is mid-shutdown — wait a moment and retry.
  • Disk is full (server/renders/ needs at least 2× the final file size in scratch space during render).

Section 12 Tips & tricks #

A grab-bag of things you'll discover eventually. Listed up front.

Zoom way in for fine-grained trim

If two clips need to butt perfectly against each other, zoom the timeline so 1 second is more than 200 px, then drag the amber handles until they snap.

Snap points include the playhead

Want a fade-in aligned to a specific frame? Move the preview to that frame, then drag your clip — it'll snap to the playhead.

Vertical 9:16 and Square 1:1 for social

Pick a Canvas preset after switching the project's intent — vertical for TikTok / Reels / Shorts, square for Instagram.

Reset timeline ≠ undo

Reset asks for confirmation, BUT it sets a single undo step. Press Ctrl+Z once after a reset and your timeline comes back.

Each slider drag = one undo step

Drag a slider, release, then move another slider. You'll see two undo steps. If you're mid-drag and want to cancel, drag past the slider's end and release — the value snaps back.

Save often, render rarely

Saves are instant. Renders take 15-60 seconds. Save before any major change, render only when you're ready to ship.

Section 13 Glossary #

Technical, AI, image- and video-generation terms you'll bump into while editing here or using adjacent tools. Alphabetized. The tags group terms by topic so you can skim for context.

Tags: vid video editing · rem Remotion · ai AI · img image generation · fx visual effects · web web / tech · anim design / animation · aud audio

A
AI (artificial intelligence) ai
A broad term for software that performs tasks normally needing human cognition — recognising images, generating text, suggesting edits. In this guide's context, AI tools often generate or enhance media (images, captions, voices) that you then drop into the editor.
API (endpoint) web
A URL path the server exposes to the client. This editor's backend exposes /api/upload (drop files here), /api/render (turn timeline into MP4), and /api/health (liveness check the docker stack polls).
AV1 vid
A modern, royalty-free video codec. Smaller files than H.264 at the same quality. The Remotion renderer supports several codec families — the default export is H.264 for maximum compatibility.
B
Bitrate audvid
Bits per second of audio or video stream. Higher bitrate = larger file, more detail. The default MP4 export uses a high enough bitrate for streaming-quality 1080p without bloating.
Bundler webrem
A tool that takes many source files (your compositions/ + React + Remotion) and packs them into one self-contained bundle that the renderer can load headlessly. @remotion/bundler wraps Webpack for this job.
C
CFG scale (classifier-free guidance) aiimg
A slider in diffusion image generators that controls how literally the model obeys your prompt. Low = creative / loose interpretation, high = strict but potentially over-saturated.
Codec vid
The compression algorithm that turns raw video frames into a stream. Common codecs: H.264 (most compatible), H.265 / HEVC (smaller files, less compatible), VP9 (open, YouTube-friendly), AV1 (newest, royalty-free).
Composition rem
A Remotion React component that takes inputProps and renders one full video. This editor has exactly one composition — MainComposition — which is fed the entire timeline JSON as its input.
ControlNet img
An add-on for Stable Diffusion that lets you guide generation with a separate input: a pose, an outline, a depth map. Useful for keeping characters consistent across many frames.
CORS (Cross-Origin Resource Sharing) web
A browser security rule that prevents JavaScript on one domain from fetching resources from another domain. The dev proxy in Vite and the nginx proxy in Docker both handle this so the React app can talk to the Express backend.
D
DALL·E aiimg
OpenAI's text-to-image diffusion model. Generates images from natural language prompts. Save your favorites as PNG/JPG and bring them into this editor via the Media Bin.
Deflicker fx
Post-processing that smooths frame-to-frame brightness changes. Useful for video collages assembled from many source clips with different exposures.
Denoising (steps / strength) aiimg
In Stable Diffusion, the "denoising strength" of an img2img pass. Higher = more change from the source. In audio, "denoising" often means removing background hiss.
Diffusion model aiimgfx
A class of generative model that learns to remove noise from images, step by step, in reverse. The basis for Stable Diffusion, DALL·E 2/3, Midjourney, Sora, Runway Gen, and most modern image / video generators. Patience is the civilization-level answer; for this guide: "the AI behind most modern image / video generators."
E
Easing anim
The shape of an animation curve. Ease-in starts slow, ease-out ends slow, ease-in-out both. Bezier curves in CSS let you define custom easings. Springs are an alternative to base easings because they have built-in physical realism.
Embedding ai
A vector representation of something (a word, an image, a video frame) as a list of floats, where similar things are close in vector space. The basis for semantic search and RAG.
Express web
The minimal web-server framework used by the editor's backend. Routes /api/* are mounted on a single Express app in server/src/index.ts.
F
Fade in / fade out audfx
A smooth ramp from silence (fade in) or to silence (fade out) for audio, and a transparency ramp for video. Used to avoid abrupt starts and stops.
FFmpeg webvid
The canonical open-source command-line tool for video and audio transcoding. Underpins most video-processing pipelines, including what @remotion/renderer uses internally to package frames into an MP4.
Fine-tuning ai
Training a pre-existing model further on a small, specific dataset so it does your task better — eg. Stable Diffusion fine-tuned on your product photos.
FPS (frames per second) vid
How many individual pictures the video plays per second. 30 fps is the default in this editor. Cinematic film is 24 fps. Higher fps = smoother motion but larger files.
Frame vid
A single still image in a video. At 30 fps, one second of video has 30 frames. Each frame is identified by an integer (0, 1, 2…) — frame N shows the timeline at exactly N / fps seconds.
Frame interpolation fxvid
Synthesizing intermediate frames between two existing frames to slow down footage (or generate higher-fps video). Modern AI tools can do this very convincingly.
G
GAN (Generative Adversarial Network) ai
An older class of generative model (predates transformers & diffusion). Two networks compete: one generates, one discriminates. Still used in some image and style-transfer tools, though diffusion has overtaken it.
H
Headless (browser) webvid
A browser (usually Chrome) running with no visible window — driven programmatically to render pages or capture frames. The editor's renderer uses headless Chrome to draw every frame of your timeline into the final MP4, so it can run on a server with no display.
I
Inference ai
Running a trained model to produce output. "Prompt → inference → image." Inference is what takes GPU time and is what API providers charge you for.
inputProps rem
In Remotion, the props the React composition receives at runtime. This editor's MainComposition has one prop: { timeline: TimelineState }.
Interpolation remanim
Computing a value at an intermediate point between two known values. Remotion's interpolate() turns frame numbers into values like opacity, scale, x. Often paired with spring().
J
JSON (JavaScript Object Notation) web
A plain-text data format. Save files are JSON (the .remotion.json extension is just convention). Reading a save file in any text editor shows the same data your timeline editor sees.
Jump-cut vid
A sharp cut between two shots at the same angle that skips time forward. Distinct from a fade — there's no overlap or transition.
K
Keyframe vidanim
A point in time where you explicitly set a property value. Software interpolates between keyframes. This editor doesn't expose keyframes directly — the entrance physics are continuous via springs — but the file format supports it.
L
Latent (space) aiimg
A compressed representation an image or video lives in inside a generative model. You don't see it directly — the model converts it back and forth between latent space and pixel space.
LLM (Large Language Model) ai
A generative model trained on huge amounts of text that produces text in response to a prompt. Examples: GPT, Claude, Llama, Gemini. Often used to draft scripts or captions that you then drop into a video editor.
LoRA (Low-Rank Adaptation) aiimg
A small, trainable patch for an existing diffusion model that teaches it a new concept (a face, a brand) with only a few dozen photos. Cheap to train, easy to share.
M
Mass / Damping / Stiffness animrem
The three ingredients of a spring. Mass = heaviness, damping = friction, stiffness = pull. The Remotion docs have a handy playground for tuning them.
Midjourney aiimg
A widely-used commercial text-to-image diffusion model. Highly stylised out of the box, popular for art-direction-heavy work.
MIME type web
A label a server attaches to a response describing the file's type, eg. video/mp4, image/png, audio/mpeg. Browsers use it to decide how to play the file.
Motion blur fxvid
A visual artifact from real cameras when objects move during the exposure. Artificial motion blur in video transitions adds realism; can also be used stylistically.
MP4 (container) vid
A file container for video + audio. The compression inside is determined by the codec (H.264, H.265…). "MP4" alone doesn't tell you the codec — but almost all consumer MP4s are H.264.
Multer web
A Node middleware for handling multipart/form-data uploads. The editor's /api/upload route uses Multer to receive dropped files from the React client.
O
Optical flow fxvid
A per-pixel motion estimate between frames. The basis for AI-driven frame interpolation and slow-motion.
P
Player (@remotion/player) rem
A React component from Remotion that renders a composition inside the browser, frame-accurately, with optional controls. The live preview in this editor is a Player wrapped in custom controls (play/pause/loop buttons).
Prompt ai
A text instruction you give a generative model. "A cat in a wizard hat, watercolour." The fundamental "programming language" of diffusion tools.
R
RAG (Retrieval-Augmented Generation) ai
A way to give an LLM access to your private documents — it retrieves relevant passages, then answers with them in context. Used to script a video using your own prior scripts as reference material.
Renderer (@remotion/renderer) rem
The Remotion package that takes a bundled composition and produces a real video file. Uses a headless browser under the hood — that's why it requires a real, server-class machine and not, say, a Lambda.
Runway ML aifx
A commercial AI video tool (Gen-1, Gen-2, Gen-3). Apply styles to existing footage or generate short clips from text. Inputs and outputs can be brought into this editor.
S
Sample rate aud
Audio samples per second (Hz). 44,100 Hz (CD quality) is common. Higher rates capture higher frequencies but use more storage.
Seed aiimg
A number that random-number-generator-generative models start from. Same seed + same prompt = same image. Useful for "I want this one but slightly different" iterations.
Sequence rem
A Remotion component that timeshifts a child. The Sequence from={5} durationInFrames={30} frame renders the child from second 5 to second 6 of the composition — used to layer clips at different times. Remotion docs.
Sora aifx
OpenAI's text-to-video diffusion model. Generates short, photorealistic-or-stylised video clips from a natural-language description. Limited release as of this guide's writing.
Spring physics animrem
An animation function that simulates a physical spring. Remotion's spring() takes frame numbers and returns a value (0 to 1) that follows spring dynamics. Each entrance in this editor uses one.
Stable Diffusion aiimg
An open-source diffusion image generator. Released by Stability AI. Many fine-tunes and control-nets built on top of it.
T
Timecode vid
A way to label a position in time. This editor uses HH:MM:SS:FF where FF is the frame number within the current second — e.g. 00:01:23:14 = 1 minute 23 seconds, frame 14.
Timeline (Remotion concept) rem
This is both the editor's UI concept (the horizontal scroll) AND a JSON value called TimelineState (compositions/src/types.ts) that's passed to MainComposition as inputProps.timeline.
Token (LLM) ai
A chunk of text (roughly 4 characters in English) that an LLM processes. "Hello world" ≈ 2 tokens. Most API providers charge by token. Long prompts with too much context can run into context-window token limits.
U
Upscaling imgfx
Increasing the resolution of an image or video. AI upscalers (Real-ESRGAN, Topaz, etc.) hallucinate plausible detail; traditional bicubic / Lanczos resamplers just blur.
V
VAE (Variational Autoencoder) ai
A neural-network architecture that compresses data into a small "latent" representation and decodes it back. Stable Diffusion uses a VAE for the image side of the pipeline.
Vite web
The dev server + bundler used by the client. Lightning-fast HMR (hot module replacement) is its killer feature for UI work.
W
WebCodecs webvid
A modern browser API for hardware-accelerated codec access. Used by Remotion's renderer to decode video frames efficiently.
